# Roamly — Travel & Tourism Website

## Problem Statement
Problem Statement 5: Travel and Tourism Website

## Objective
To develop a responsive and user-friendly tourism website
showcasing popular destinations, travel packages, attractions
and travel-related information using HTML, CSS and JavaScript.

## Features
- Responsive website for desktop and mobile devices
- Travel destination search
- Destination category filters
- Favourite destination saving
- Travel package carousel
- Trip enquiry form with validation
- Newsletter subscription demonstration
- Mobile navigation menu
- Interactive messages and notifications

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- Vercel

## Project Structure
- index.html — Website structure
- style.css — Website styling and responsive design
- script.js — Interactive functionality
- README.md — Project documentation

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Ensure all files are in the same folder.
4. Open index.html in a browser.
5. An internet connection is required for online images and fonts.

## Deployment
This project can be deployed on Vercel as a static website.
No build command is required.
